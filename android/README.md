# Glide Remote Android client

Open this folder in Android Studio and run the `app` configuration, or build from a terminal with `gradlew.bat assembleDebug`. Tap **Scan PC QR Code** and scan the desktop QR. The client supports touchpad movement, left/right click, two-finger scrolling, media controls, and optional motion control.

Both devices must be on the same network. The project uses ZXing for scanning and OkHttp for the existing Glide WebSocket protocol.
